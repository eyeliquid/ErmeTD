# Game design

Tower defense game in de art style van red alert 3.
25 spelers in hun eigen veld. Je kan vrij rondlopen met een builder op je eigen veld. Met de camera kan je ook bij de actieve spelers kijken.
Als je het spel joined kom je bij elkaar in een lobby. De eerste speler kan het spel starten als iedereen compleet is. De andere spelers kunnen op een start knop drukken..en als iedereen akkoord  is start het spel.
Er zijn 50 rondes. Elke ronder moeilijker dan de rond ervoor.
10 verschillende turrets. Denk aan ice om te bevriezen en poison om de vijanden langzamer te laten gaan.
Als een turret 5 keer geupgrade is kan je kiezen om een turrent te linken met naburige geupgrade turrets. Of om een turbo turrent te maken. 
Bij 3 turbo turrets ontstaat er een superduper turrets genaamd "the geers".
De highscores van de spelers worden op een leaderboard gezet. Die zichtbaar is als je de website opkomt. Deze score wordt gedeeld met iedereen die wil meedoen.

Elk potje levert xp op. Meer als je op de hogere levels komt.
Hiermee kan je een skills kopen. 
Er zijn 20 skills. Zoals meer gold per kill of lagere upgrade kosten.
Maak het zo dat het spel pas uit te slepen is als je ongeveer 15 skills heb gekocht. Hiervoor moet je ongeveer 50 games hebben gespeeld.
